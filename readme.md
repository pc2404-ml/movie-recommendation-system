# 🎬 Movie Recommendation System

This project is a **Content-Based Movie Recommendation System** built using **Machine Learning** techniques. It suggests movies similar to the one selected by the user, based on metadata like genres, keywords, cast, and crew.

## 🚀 Features

- Recommend top 5 similar movies based on selected input
- Uses **cosine similarity** and **TF-IDF vectorization**
- Integrated with **TMDb API** to fetch movie posters
- Built using **Python** and **Streamlit** for the web interface

## 🧠 Tech Stack

- Python
- Pandas, Scikit-learn, Numpy
- TMDb API
- Streamlit

## 💻 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/pc2404-ml/movie-recommendation-system
   
  
2. Install the dependencies:
   pip install -r requirements.txt

3.Add your TMDb API key in the script where applicable.
4.Run the Streamlit app:
  streamlit run app.py
